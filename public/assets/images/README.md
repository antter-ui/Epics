# Image Assets Replacement Guide

To respect copyright and licensing terms, proprietary stock photographs from the ThemeForest reference demo are **not** copied into this directory.

Instead, all photographic slots map to open-license Unsplash medical/wellness photographs (Unsplash License) matching the exact reference dimensions and aspect ratios documented in `../../asset-inventory.md` (and reusing the verified specialist portraits already seeded in `server/db.js`).
